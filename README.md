# Bashir — YemenBook

تطبيق مجتمع اجتماعي مبني بـ Expo وReact Native. يقدم منشورات ووسائط وتفاعلات ورسائل وسوق C2C مباشر بين المستخدمين. السوق لا يتوسط في الاتفاق أو التسليم ولا يفرض عمولة.

## الاتصال بالخدمة الخلفية

يعتمد المشروع على Supabase. نفّذ ملف `supabase/schema.sql` داخل SQL Editor لمشروع Supabase، ثم أنشئ ملف `.env` من `.env.example` وضع فيه المفتاح العام `anon` فقط. لا تضع مفتاح `service_role` في التطبيق مطلقاً.

```bash
cp .env.example .env
pnpm install
pnpm start
```

## ملاحظات النشر

يحتوي المصدر على طبقة حسابات ومنشورات ووسائط وتفاعلات وتعليقات ورسائل وسوق وطلبات ترقية منشور تخضع لمراجعة يدوية. لا يحتوي على أي محافظ أو اشتراكات أو تحقق هوية أو تحصيل تلقائي داخل التطبيق.
