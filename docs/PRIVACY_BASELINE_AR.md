# أساسيات الخصوصية في YemenBook

يجب نشر سياسة خصوصية عامة قبل إطلاق الحسابات أو الرسائل أو رفع الوسائط للمستخدمين. تجمع النسخة المتصلة الحد الأدنى من بيانات الحساب، مثل الاسم ورقم الاتصال والصورة الشخصية والمنشورات والوسائط والرسائل، لتقديم الخدمة فقط.

تُخزن البيانات في مشروع Supabase المحدد من مالك المنصة. يحظر استخدام مفتاح `service_role` داخل تطبيق الهاتف. يجب استخدام المفتاح العام فقط مع RLS، ويجب أن تسمح سياسات قاعدة البيانات للمستخدم بالوصول إلى بياناته ورسائله فقط.

يلزم توفير أدوات للإبلاغ والحظر وحذف الحساب أو طلب حذف البيانات، ومراجعة البلاغات بصورة مستمرة قبل الإطلاق العام.
