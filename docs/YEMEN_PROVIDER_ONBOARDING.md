# YemenBook — قائمة onboarding لمزودي الدفع اليمنيين

## الاستخدام

تُستخدم هذه القائمة بعد تسجيل الكيان القانوني في اليمن وقبل إدخال أي بيانات اعتماد في الخادم. لا تعتمد هذه الوثيقة على أن بوابة دفع بعينها متاحة أو مناسبة؛ يجب أن يؤكد المزود ذلك كتابةً ضمن عقد التاجر ووثائق API الخاصة به.

## ملف الأعمال الموحد

| المستند أو المعلومة | الغرض |
|---|---|
| اسم الكيان القانوني، السجل التجاري، والرقم الضريبي إن وجد | فتح حساب تاجر والتحقق من صاحب النشاط. |
| العنوان التشغيلي الدائم وبيانات المسؤول المخول | استيفاء متطلبات التاجر والتواصل التشغيلي. |
| وصف YemenBook وتدفقات المتجر والإعلانات والاشتراكات | تقييم المخاطر والمنتجات التي يحتاجها الحساب. |
| سياسة الخصوصية، الشروط، سياسة الاسترداد والنزاعات | الإفصاح للمستخدمين ومعالجة الاعتراضات. |
| مخطط تدفق الدفع والسحب والعمولات | مراجعة الالتقاط والتسوية وعمولة 5% وأرباح المنشئين. |
| بريد تشغيلي وفريق دعم ومسار تصعيد | معالجة فشل الدفع والاعتراضات والاشتباه بالاحتيال. |

## بنك الكريمي

الصفحة الرسمية لبنك الكريمي تعرض خدمة «الربط API» لربط التطبيقات أو المواقع بالمصرف لتسهيل الدفع، كما تعرض قنوات وتفاصيل اتصال. [1] وتذكر الأسئلة الشائعة متطلبات ظاهرية لقبول دفع «حاسب» في نشاط تجاري، منها عنوان نشاط دائم، حساب باسم النشاط، وتوقيع اتفاقية خدمة في الفرع. [2]

| يطلب من البنك | لا تقبل بدونه |
|---|---|
| تأكيد أن حساب التاجر المؤهل لـ YemenBook يدعم API للتطبيق أو الموقع | لا يبنى اتصال استناداً إلى واجهة المستهلك فقط. |
| وثيقة API، عناوين Sandbox وProduction، ومخطط توقيع webhook | لا تضف endpoint أو توقيعاً من مصادر غير رسمية. |
| شروط التسوية والاسترداد والنزاعات وحدود المعاملات | لا تحسب أرباح منشئين أو سحوبات بناء على افتراضات. |
| تأكيد مسار المدفوعات الصادرة إن كان مطلوباً للسحب | لا تفعّل الحد الأدنى 100 دولار أو السحب قبل ذلك. |

## محفظة جوالي

يعرض موقع جوالي الرسمي خدمات المحفظة ونموذجاً للانضمام كوكيل، لكنه لا يعرض في الصفحة المسترجعة مرجع API تاجر علنياً. [3]

| يطلب من جوالي | لا تقبل بدونه |
|---|---|
| جهة مبيعات/شراكات تاجر رسمية | لا تستخدم أي مكتبة أو endpoint من مصدر غير رسمي. |
| مواصفات التاجر وبيئة اختبار وتوقيع webhook | لا تُفعّل أي زر دفع حي داخل التطبيق. |
| حدود الرسوم والتسوية والاسترداد | لا تؤكد طلبات المستخدم أو عمولات المنصة. |

## محفظة جيب

يعرض موقع جيب الرسمي المحفظة وخدمات الشحن والسداد والدعم، لكن الصفحة المسترجعة لا تتضمن مرجع API تاجر علنياً. [4]

| يطلب من جيب | لا تقبل بدونه |
|---|---|
| تأكيد برنامج تاجر أو تكامل تطبيقات | لا تفترض توفر بوابة دفع لتطبيق YemenBook. |
| وثائق API واختبار وwebhook موقّع | لا تحفظ أسراراً أو تنفذ عملية من الهاتف. |
| سياسة التسوية والاعتراضات والحدود | لا تعرض وعداً بسحب أو استرداد للمستخدمين. |

## اختبار ما قبل الإطلاق

يبدأ كل مزود في Sandbox أو بيئة اختبار متحكم بها. ينشئ الخادم طلب اختبار، يتلقى webhook موقّعاً، يسجل أحداثاً idempotent في دفتر أستاذ، ثم يختبر الإلغاء والاسترداد والتكرار وفشل الشبكة. لا ينتقل التطبيق إلى production لمزود بعينه إلا بعد اعتماد المنتج والأمن والعمليات لهذه الاختبارات.
