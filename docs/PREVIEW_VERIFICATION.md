# التحقق من المعاينة

في المحاولة الأولى لفتح معاينة يمن بوك على المنفذ 8084، ظهرت صفحة فارغة بعد تحميل الصفحة، ولم يظهر خطأ في سجل المتصفح. سيتم فحص حزمة Metro وسجل الخادم لتحديد سبب عدم تركيب واجهة React Native Web.

عند إعادة فتح المعاينة بمعلمة إصدار جديدة، ظهرت بوابة الدخول بنجاح مع الهوية الحمراء، وعنوان YemenBook - يمن بوك، وحقول الاسم ووسيلة التواصل وكلمة المرور، وأزرار إنشاء الملف المحلي والدخول إلى المحاكاة، وتبديل اللغة والمظهر.

تم استخدام بيانات اختبار غير حقيقية لإنشاء ملف محلي بنجاح. انتقل التطبيق إلى الصفحة الرئيسية وأظهر شريط حدود المحاكاة والقصص ومحرر المنشور وبطاقات المنشورات وتفاعلات الإعجاب والتعليق والمشاركة والحفظ والإبلاغ، إضافة إلى اقتراحات الصفحات والوظائف والإعلان التوضيحي.

تم فتح Marketplace من التنقل السفلي، وظهرت فلاتر المدينة والفئة وبطاقات إلكترونيات وسيارات وعقارات وأثاث مع أزرار مراسلة ودفع محاكى. وتم اختبار فلتر مدينة تعز بنجاح، فاقتصر العرض على بطاقة العقار المرتبطة بهذه المدينة.

تم فتح قائمة المزيد، وظهرت مداخل المجموعات والرسائل والصفحات والأحداث والوظائف والألعاب والملف والأمان والإدارة والإعدادات. ثم فُتح Messenger المحلي بنجاح مع محادثة توضيحية وردود سريعة وحقل كتابة ومؤشرات صريحة بأن المكالمات والوسائط والمرفقات واجهات محاكاة فقط.

تم إدخال رسالة اختبار ثم إرسالها عبر Messenger. ظهرت الرسالة داخل المحادثة المحلية مع إشعار نجاح، ولم يتم الاتصال بأي طرف أو خدمة خارجية.

تم الوصول إلى لوحة الإدارة من قائمة المزيد. عرضت اللوحة مؤشرات محلية للمستخدمين والمنشورات والبلاغات والإعلانات والسوق والإحصاءات، مع إفصاح ظاهر بأنها لا تدير مستخدمين أو محتوى حقيقيين.

تم فتح الإعدادات، وظهرت مفاتيح المظهر والإشعارات وحالة API المحاكية، إضافة إلى اختيار 12 لغة: العربية والإنجليزية والفرنسية والتركية والإندونيسية والألمانية والإسبانية والبرتغالية والهندية والأردية والسواحلية والروسية.

تم تبديل الوضع الداكن بنجاح، ثم اختيار الإنجليزية. تحولت عناوين الإعدادات والتنقل وإفصاح المحاكاة إلى الإنجليزية مع بقاء الحساب المحلي والجلسة قائمين.
