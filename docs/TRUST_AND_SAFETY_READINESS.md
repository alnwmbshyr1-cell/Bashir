# YemenBook — جاهزية الاعتدال وإدارة الحوادث

## نطاق العمل

تطبيق يمن بوك الحالي لا يرسل رسائل أو مكالمات أو وسائط حقيقية. قبل تشغيل أي من هذه الخدمات، يجب أن يصبح الإبلاغ والحظر والاعتدال وتدقيق القرارات خدمات خادمية تشغيلية لا أزرار واجهة فقط.

## تدفق الإبلاغ والحظر

| خطوة | ما يحدث في الخادم | قاعدة الأمان |
|---|---|---|
| إبلاغ | ينشئ المستخدم بلاغاً بنوع المحتوى والسبب والمرجع. | لا يظهر المبلغ عن هويته للطرف المبلّغ عنه. |
| فرز | تصنف القواعد والخدمة البلاغ حسب الخطورة. | لا يحذف المحتوى آلياً نهائياً بلا سجل ومراجعة قابلة للتدقيق. |
| مراجعة | يراجع مشرف مخول المحتوى والسياق وسجل البلاغات. | صلاحيات المشرف محدودة ومسجلة. |
| قرار | يبقى المحتوى أو يقيّد أو يحذف أو يجمّد الحساب. | يسجل سبب القرار والزمن والمراجع. |
| اعتراض | يستطيع المستخدم الاعتراض ضمن سياسة محددة. | لا يعيد الاعتراض المحتوى المحذوف تلقائياً. |
| حظر | يمنع التواصل والوصول المتبادل وفق السياسة. | يطبق الحظر في الرسائل، المحتوى، البحث والدعوات. |

## درجات الأولوية

| الدرجة | أمثلة تشغيلية | استجابة مطلوبة |
|---|---|---|
| حرجة | خطر مباشر، استغلال، احتيال مالي، اختراق حساب | تجميد وقائي، تصعيد عاجل، حفظ سجل الأدلة. |
| عالية | انتحال، تهديد، خطاب كراهية، احتيال متكرر | مراجعة سريعة، تقييد مؤقت عند الحاجة. |
| متوسطة | إساءة، سبام، انتهاك خصوصية محدود | فرز ومراجعة ضمن هدف زمني محدد. |
| منخفضة | محتوى غير مرغوب أو تكرار بسيط | أدوات تحكم للمستخدم وفرز تلقائي متحفظ. |

## إدارة الحوادث

يُنشأ حادث عندما تتجاوز الأحداث بلاغاً منفرداً، مثل تسرب بيانات أو احتيال واسع أو إساءة منظمّة أو عطل في الدفع. يعيّن قائد حادث، ويحفظ الخط الزمني، ويوقف الجزء المتأثر بمفتاح إيقاف خادمي، ثم يراجع السبب الجذري والإجراءات التصحيحية قبل إعادة الخدمة.

## ما يجب أن يسبق الإطلاق

| المجال | الحد الأدنى |
|---|---|
| الهوية والصلاحيات | حسابات مشرفين محمية بوسيلة تحقق قوية ومراجعة دورية للصلاحيات. |
| التخزين | فصل ملفات الوسائط عن بيانات الحساب، تشفير وحذف منضبط. |
| السجلات | سجل تدقيق للبلاغات وقرارات المشرفين وتغييرات الحظر والصلاحيات. |
| العمليات | جدول مناوبة، قناة تصعيد، ووقت استجابة للبلاغات الحرجة. |
| السياسات | إرشادات مجتمع، سياسة خصوصية، سياسة إنفاذ واعتراض قابلة للوصول. |
| التقييم | اختبار إساءة الاستخدام والتقارير والحظر قبل فتح رفع الوسائط أو الرسائل. |

## نقطة الإطلاق

تبقى الرسائل والوسائط والبث الحي غير مفعلة حتى تُنفذ هذه المتطلبات على الخادم وتُختبر مع فريق الاعتدال. لا يفتح YemenBook العمليات الحية لأن شاشة الواجهة تعرضها فقط.
