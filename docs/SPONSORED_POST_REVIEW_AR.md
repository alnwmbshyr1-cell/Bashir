# سياسة طلب ترقية المنشور

تتيح YemenBook تقديم طلب لترقية منشور لمدة **سبعة أيام** مقابل قيمة معلنة قدرها **5 دولارات** عبر تحويل خارجي إلى بنك الكريمي. التطبيق لا ينفذ التحويل ولا يربط بأي بنك أو محفظة.

## التسلسل التشغيلي

1. يختار المستخدم منشوراً يملكه ويطلب ترقية المنشور.
2. تظهر تعليمات التحويل الخارجية، ثم يرفع المستخدم صورة أو ملف إيصال الطلب.
3. يسجل التطبيق الطلب بحالة `pending_review` فقط.
4. يراجع مالك المنصة الإيصال والمحتوى يدوياً من لوحة Supabase. لا توجد موافقة تلقائية.
5. عند الموافقة اليدوية فقط، تضبط الإدارة تاريخ البداية والنهاية لمدة سبعة أيام وتتحول الحالة إلى `approved`.

> لا تضع مفاتيح بنك أو تفاصيل وصول مصرفية داخل التطبيق. هذا المسار توثيق ومراجعة يدوية فقط، ولا ينفذ تحويلات أو استردادات أو محافظ أو اشتراكات.

## المحتوى غير المقبول

يُرفض أي طلب يخالف سياسة المجتمع أو يتضمن احتيالاً أو ادعاءات مضللة أو محتوى ممنوعاً. ويمكن إيقاف ترقية منشور معتمد إذا ظهر لاحقاً أنه يخالف السياسة.
